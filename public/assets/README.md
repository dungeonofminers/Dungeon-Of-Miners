# Image assets

Drop your final image files into this folder using these exact names. The
site reads every path from `src/content/site.ts` (the `assets` object), so
as soon as a file appears here with the matching name, it replaces the
on-brand placeholder automatically — no code changes needed.

| Filename | Used for |
| --- | --- |
| `logo-dom.png` | Main DOM logo (navbar, footer, hero) |
| `logo-dragon-coin.png` | Alternate coin mark, available for future use |
| `logo-miner-hat.png` | Alternate mark, available for future use |
| `hero-dungeon.png` | Hero section main illustration (16:9) |
| `miniapp-mine-screen.png` | Mini App screenshot — Mine tab |
| `miniapp-earn-screen.png` | Mini App screenshot — Earn tab |
| `miniapp-boost-screen.png` | Mini App screenshot — Boost tab |
| `miniapp-referral-screen.png` | Mini App screenshot — Referral tab |
| `miniapp-me-screen.png` | Mini App screenshot — Profile/Me tab |
| `floor-rubble.png` | Floor 1 — Rubble |
| `floor-hollow.png` | Floor 2 — Hollow |
| `floor-gloom.png` | Floor 3 — Gloom |
| `floor-ember.png` | Floor 4 — Ember |
| `floor-cinder.png` | Floor 5 — Cinder |
| `floor-abyss.png` | Floor 6 — The Abyss |

Recommended sizes: logos as square PNGs (min 256×256, transparent
background), hero/floor art at 1600×900 or larger.
